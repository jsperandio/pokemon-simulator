# Music

To play music within the game, you must first select a file to play. This is done by selecting Music|Open file..., and selecting the file to play. By default, the file selector will show the following files:

- MPEG Audio Files (\*.mp3)
- Ogg Vorbis Files (\*.ogg)
- Wave Files (\*.wav)

These file types can also be seen using one of the above filters. Just click the box where it says "All supported formats".

Once ready, the file will automatically begin to play. To stop it, select Music|Stop Music.

By default, the music will repeat endlessly. To toggle this, select Music|Repeat Music. If this is not checked, the music will stop once it has finished playing. You must then open a new song to continue, or re-open the same one.
