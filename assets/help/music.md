# Music

> **Port note:** This page describes the original Windows game, which played music through Windows Media Player. The port has its own player, which plays MP3, Ogg Vorbis and WAV files, and not WMA, MIDI or video. The file types and Windows Media Player instructions below don't apply to it. Repeat Music and Stop Music work as described.

To play music within the game, you must first select a file to play. This is done by selecting Music|Open file..., and selecting the file to play. By default, the file selector will show the following files:

- MPEG Audio and video files (\*.mp3, \*.mpeg, \*.mpg, \*.mpe, \*.m1v, \*.mp2, \*.mpv2, \*.mpa)
- Windows Media files (\*.wma, \*.wmv)
- Wave Audio (\*.wav)
- MIDI files (\*.mid, \*.midi, \*.rmi)

These file types can also be seen using one of the above filters. Just click the box where it says "All supported formats".

As you can see, videos are also supported! When playing a video, a window will appear showing the picture. However, if your system is set to play videos in full-screen, it may switch to full-screen when starting the video. If this happens, press Alt-Enter. This should switch to windowed mode.If that doesn’t work, try to press Alt-F4. This will stop the file.

The formats actually supported may vary. The file types mentioned above have been selected because they are present on most or all computers. These are always present, and will not be changed as you add or remove support for different files. To select other file types, select "All files" from the type selector, or type \*.\* in the filename box.

To find out whether your file will play, click here to open Windows Media Player. Open the file. If it won't play, you can't use it with the game.

*NOTE: Playlists may not work. You can't change between tracks in a playlist.*

Once ready, the file will automatically begin to play. To stop it, select Music|Stop Music.

By default, the music will repeat endlessly. To toggle this, select Music|Repeat Music. If this is not checked, the music will stop once it has finished playing. You must then open a new song to continue, or re-open the same one.

This feature makes use of the same functions as the Windows Media Player (WMP), and is basically a minimal version of this. As such, it can use any codec supported by WMP. For those of you who don't know, the word codec (*pl. codices*) is an acronym meaning "compression-decompression". A codec adds support for playback of one or more file types.

It is possible to get more codices on the internet. Once a codec has been installed, the game can play the file types supported by that codec.
